# Report fonts

PDF exports embed **Poppins** (Regular, Medium, SemiBold) so reports match the web app.

Poppins is copyright 2020 The Poppins Project Authors (https://github.com/itfoundry/Poppins) and is
licensed under the SIL Open Font License, Version 1.1 (https://openfontlicense.org), which allows the
fonts to be bundled and embedded in documents.

If these files are missing, the PDF writer falls back to Helvetica automatically.
